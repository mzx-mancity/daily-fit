# 小橘爱运动 · 使用说明

> 简介 + 安卓 / 苹果下载安装,一页看完。

## 这是什么

一个**完全离线**的健身记录 App,打开就是日历,一眼看到哪天练了什么。

- 📅 **日历记录**:有氧(蓝)/ 无氧(橙)/ 休息(绿)用底色区分,点哪天看哪天,左右滑动翻月
- ✅ **自定义项目**:臀 / 腿 / 肩 / 胸 / 背 / 手臂 / 核心 / 跑步……做完打勾,一键确认保存
- 💧 **喝水记录**:按杯记,环形进度可视化,近 7 天柱状图;并按你的体重给出**建议饮水量**
- 📊 **BMI**:填身高体重自动算,并记录体重历史

无需账号、不联网也能用、数据只存在你自己手机里。安装包只有约 75KB。

## 🍎 苹果怎么装(iPhone / iPad)

苹果不支持直接装 APK,用苹果官方支持的**「添加到主屏幕」**方式,效果和 App 一样:
全屏、无地址栏、断网可用、桌面有独立图标。

**必须用 Safari**(微信内置浏览器、Chrome 里没有这个选项)

1. Safari 打开:**https://mzx-mancity.github.io/daily-fit/**
2. 点屏幕**底部中间的分享按钮**(方框 + 向上箭头 ↑)
3. 菜单往下滑,点 **「添加到主屏幕」**
4. 右上角点 **「添加」**

回到桌面,就有橘色的「小橘爱运动」了。

> App 里「我的 → 使用说明」也可以直接看图文说明(应用内弹层,不会跳转)。

> **更新**:从桌面图标打开后**下拉刷新**即最新版,不用重装。
> 如果一直是旧界面:长按桌面图标删除,再按上面步骤重新添加一次。

## 常见问题

**Q:苹果为什么不能装 APK?**
A:iOS 只允许通过 App Store 或 TestFlight 安装原生 App,而这两者都需要苹果开发者账号(每年 688 元)和 Mac 编译。
「添加到主屏幕」是苹果官方支持的替代方式,体验几乎一致,而且免费。

**Q:数据会丢吗?**
A:正常使用不会,存在手机本地。但清理 Safari 网站数据 / 卸载 App / 清除 App 数据会一起清掉。

**Q:换了新手机怎么办?**
A:目前没有导出功能,换机会从零开始。如果这个需求重要,可以告诉我,我再想办法。

**Q:要不要联网?**
A:第一次打开需要联网加载,之后断网也能记录(离线缓存)。
