# 每日 Fit · 锻炼打卡

> 在线试用:<https://mzx19159506939-del.github.io/daily-fit/> ｜ 安卓安装包:[Releases](https://github.com/mzx19159506939-del/daily-fit/releases/latest)

一款**本地离线优先**的手机健身打卡 + 饮食 + 喝水 + BMI PWA(Progressive Web App):记录每天的有氧/无氧/休息日、自定义锻炼项目(臀腿肩...)、每日饮食卡路里、喝水量和 BMI。无需注册、无需服务器,数据只存在你手机浏览器的本地存储里。

## 功能

### 🏋️ 锻炼打卡
- 顶部日期卡:自动显示**日期 + 周几**,左右箭头可补记/修改任意一天
- 每日运动类型三选一:**有氧运动 / 无氧运动 / 休息日**
- **自定义锻炼项目**:手动输入或点快捷标签(臀 / 腿 / 肩 / 胸 / 背 / 手臂 / 核心 / 跑步 / 跳绳 / 游泳 / 骑行 / 瑜伽),每个项目可填详情(如"深蹲 4×12")
- **逐项勾选 + 确认保存**:每个项目前有勾选框(今天真的做了就打勾),填完后勾「我已核对以上数据」再点**确认保存**,才算这天打卡完成;确认之后再改任何数据会自动退回「待确认」
- **全部记录**:按月分组列出所有打卡过的日期(类型 / 项目 / 饮食 / 喝水 / 是否已确认),点一行直接跳到那天
- **连续打卡天数 + 近 7 天打卡概览**

### 🔗 Keep 数据导入(有氧记录)

Keep **没有开放第三方接口**(官方不提供 API / OAuth,社区里的 keep_sync 脚本用的是它未公开的私有接口,需要你的登录令牌,而且浏览器端会被 CORS 拦掉),所以这里不做自动同步,而是提供两种务实的方式:

**① 截图识别(推荐)**——点「选择截图 / 拍照识别」,选一张 Keep 运动记录的截图:

> 装 APK 的话请用 **v1.2.0 及以上**:更早的版本里 WebView 没有接管网页的选文件请求,这两个按钮点了没反应(网页版 / 浏览器里不受影响)。相册走系统文件选择器,**不需要存储权限**;拍照只需要相机权限。

- 用 [tesseract.js](https://github.com/naptha/tesseract.js) 在**手机本地**做 OCR,图片**不上传任何服务器**
- 识别引擎、中文+英文语言包都打包在仓库 `vendor/tesseract/`(约 11MB),首次点用时加载一次,之后 Service Worker 缓存,离线也能用
- 识别出的文字会填到输入框,**可以手动改**,再点「解析并导入」
- 针对 OCR 的常见误读做了容错:`干卡/于卡`→千卡、`D.00`→5.00、`公里`被认成别的字时按「距离型运动 + 带小数的数字」兜底、消耗数字取 `消耗` 后面的数
- 一张列表截图有多条记录会自动拆成多条(按日期切块);**周几不用认**,由日期自动算

**② 粘贴文字**——把 Keep 运动分享里的文字直接粘进来,一行一条,自动识别成当天的有氧记录
- 支持识别:日期(`11月20日` / `2026-11-20` / `2026/11/20`)、运动项目(跑步 / 骑行 / 游泳 / 跳绳 / 快走 / 椭圆机 / 划船 / 爬楼登山 / 跳操 / 瑜伽 / 力量训练)、距离(公里 / km)、时长(`00:32:15` / `32分钟` / `1.5小时`)、消耗(`320千卡` / `320kcal`)
- 文字里**没写消耗**时,按「项目 MET × 你的体重 × 时长」估算(体重取自「我的」页,没填按 60kg)
- 导入后:当天运动类型记为有氧,项目写进锻炼清单,消耗记到当天的运动消耗里,饮食页会显示「净摄入」

示例(粘一行就能导入):

    11月20日 跑步 5.00 公里 用时 00:32:15 消耗 320 千卡

### 🍚 饮食记录(卡路里)
- 按**早餐 / 午餐 / 晚餐 / 加餐**分类记录,每天独立
- 内置 24 种常见食物一键记录(香蕉 105、米饭 174、鸡腿 181、鸡蛋 78、牛奶 155...)
- **自定义食物**:填名称 + 卡路里即可加入常用区,下次一键复用
- 份数可 0.5 步进调整(*吃完两碗米饭就点两下 +)*
- 今日摄入 / 目标进度条 / 还可摄入(超标变橙并提示"已超出")
- 每日目标默认 1800 kcal 可改;有 Keep 运动消耗时显示**净摄入**
- 近 7 天摄入柱状图

### 💧 喝水记录
- 按**水杯容量 × 杯数**记录:容量默认 250ml、每日目标默认 5 杯,均可修改
- 环形进度实时显示 已喝杯数 / 总 ml
- 一键"记一杯"、撤销、自定义 ml(小杯也能记)
- 近 7 天饮水量柱状图

### 📊 我的(BMI)
- 输入身高体重,一键计算 **BMI**(按中国成人标准分级:偏瘦 <18.5 / 正常 18.5–23.9 / 超重 24–27.9 / 肥胖 ≥28)
- BMI 色带刻度指针
- 体重自动记录历史
- 数据**导出/导入 JSON** 备份

## 安卓安装包(APK)

Release 里提供 daily-fit-1.2.0.apk(约 6.5MB,minSdk 24 / Android 7.0+,targetSdk 34),
安装后是独立 App,不用联网、不连服务器,数据只在本机。

手机安装步骤:

1. 下载 APK 到手机(微信/QQ 传文件可能改名,建议浏览器下载或数据线拷贝);
2. 点击安装 → 系统提示「未知来源应用」时允许该来源安装;
3. 打开「轻记健身」,首次识别 Keep 截图会慢 5-10 秒(加载 OCR 引擎),之后走缓存。

> 这个 APK 就是把同一套网页资源装进 WebView 的容器:资源通过
> https://appassets.androidplatform.net/ 这个虚拟域名映射到 APK 内的 assets/public/,
> 因此 localStorage、Canvas、Web Worker(OCR 的 wasm)都正常工作。
> 不想装 APK 也可以浏览器打开 Pages 地址后「添加到主屏幕」,功能完全一样。

打包方法见 docs/BUILD_ANDROID.md。

## 使用(手机安装)

1. 用手机浏览器(推荐 Chrome / Edge / Safari)打开 GitHub Pages 地址
2. 安卓 Chrome:菜单 → **添加到主屏幕**;iPhone Safari:分享 → **添加到主屏幕**
3. 桌面图标出现后,全屏独立运行,离线也能用(Service Worker 缓存)

## 部署到 GitHub Pages

推送到 GitHub 后:仓库 Settings → Pages → Source 选 main 分支 /(root)→ 保存,几分钟后得到 https://<用户名>.github.io/<仓库名>/ 。

### v1.2.0 (2026-11-22)

- 修:**APK 里点「选择截图 / 拍照识别」毫无反应**(真机反馈的 bug)。
  根因在安卓容器而不在网页:WebView 的默认 `WebChromeClient` 不实现 `onShowFileChooser`,
  网页里 `<input type="file">` 的点击事件在 WebView 中被静默丢弃,所以按钮看着能按、实际什么都不发生。
  修法:MainActivity 重写 `onShowFileChooser`,相册请求交给系统文件选择器(ACTION_GET_CONTENT / SAF),
  `capture` 请求走 ACTION_IMAGE_CAPTURE;新增 `CacheFileProvider` 把照片目录暴露成 `content://com.mzx.dailyfit.files/…`,
  规避 Android 7+ 的 FileUriExposedException;相机权限被拒时自动退化为文件选择器,不让按钮变成死键。
- 改:网页版版本号 v1.2;文档补充「选图/拍照为什么需要 Java 代码」与新增的 Provider 类。
- 说明:**不需要申请存储权限** —— 相册走系统文件选择器(SAF),App 拿到的只是你选中的那张图的临时读权限,
  比「读取整个相册」更安全;只有拍照会弹相机权限。
### v1.1.0 (2026-11-22)

- 修:手机上打开「饮食」页时整页被撑宽,底部四个 tab 里的「锻炼」被挤出屏幕。
  根因是 `flex` 行里的 `<input>` 默认 `min-width:auto`(最小内容宽约 177px),屏幕窄时装不下就把整页撑出横向滚动;
  Android WebView 中固定定位的 tabbar 会跟着布局视口一起被推出去。
  修法:`.add-row input` / `.set-grid label` 改 `flex:1 1 0; min-width:0`,tabbar 改 `left:0; right:0; margin:0 auto`(不再 `translateX(-50%)`),
  `html,body` 加 `max-width:100%; overflow-x:hidden` 兜底。
- 改:Service Worker 由「缓存优先」改为「网络优先、断网回落缓存」(`vendor/` 大文件仍缓存优先),
  以后改 CSS/JS 刷新即生效;缓存版本升到 `dailyfit-v4`。
- 加:自测新增布局回归用例 L1-L8,共 50 项断言。

## 技术说明

- **零依赖零构建**:原生 HTML/CSS/JS 单页,任何编辑器可直接改
- 数据模型:localStorage 键 fitlog_v1,按日期键存每天记录
- PWA:manifest.webmanifest + sw.js(网络优先、断网回落缓存;`vendor/` 大文件缓存优先)
- 无浏览器也能自测:`node tools/smoke_test.js`(用 node:vm 造假 DOM,50 项断言覆盖锻炼/喝水/BMI/饮食/Keep 解析/OCR 文本纠错/小屏横向溢出回归)
  - 还可回放真实 OCR 输出:`OCR_TEXT=某文件.txt node tools/smoke_test.js`
- 截图识别:tesseract.js v5 + 中文语言包,全部打包在 `vendor/tesseract/`,不依赖 CDN
- ⚠️ 因为是 Service Worker + Web Worker,必须用 `http(s)://` 打开(直接双击 `file://` 打开时识别与离线缓存都不可用)

目录结构:

    index.html            四页单页 + 底部 Tab
    css/style.css         移动端优先样式
    js/app.js             全部逻辑(存储/渲染/事件)
    sw.js                 Service Worker
    manifest.webmanifest  PWA 清单
    icons/                应用图标
    vendor/tesseract/     OCR 引擎 + 语言包(约 11MB,离线可用)
    tools/make_icons.py   图标生成脚本(Pillow)
    tools/smoke_test.js   假 DOM 自测(50 项断言)
