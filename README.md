# 小橘爱运动 · 锻炼打卡

> 网页版 / 苹果安装:<https://mzx-mancity.github.io/daily-fit/>  
> 安卓最新版(固定地址,每次更新都覆盖它):<https://mzx-mancity.github.io/daily-fit/download/latest.apk>  
> 一页看完的说明:[docs/USAGE.md](docs/USAGE.md)

一款**本地离线优先**的手机锻炼打卡 App:日历回看每天练了什么,支持有氧 / 无氧 / 休息日、自定义项目、
逐项勾选与确认保存,另有喝水和 BMI。无需注册、无需服务器,数据只存在你手机本地的存储里。

## 功能

### 🏋️ 锻炼(日历 + 当天详情)

- **月历视图**:像手机自带日历那样一屏看整月,每天用底色区分 **有氧(蓝)/ 无氧(橙)/ 休息(绿)**,
  已确认的日子右下角有 ✓;今天有描边,选中日加粗描边
- **点任意一天** → 下方立刻显示那天练了什么(类型 + 项目清单),可以直接改;日历上左右滑动翻月
- 头部一眼看到 **连续打卡天数** 和 **本月记录天数**,不在本月时出现「回到今天」
- 每天三选一:有氧 / 无氧 / 休息日(再点一次取消)
- **自定义项目**:手输或点快捷标签(臀 / 腿 / 肩 / 胸 / 背 / 手臂 / 核心 / 跑步 / 跳绳 / 游泳 / 骑行 / 瑜伽),
  每项可填详情(如「深蹲 4×12」),可逐个打勾表示做完了
- **沿用上次**:某天没记录时,一键把上次的项目和类型抄过来
- **确认保存**:勾「我已核对以上数据」后才能保存,保存后该天标记为已确认;
  之后任何改动都会自动退回「待确认」,避免把没核对的数据当成已完成

### 💧 喝水

- 按**水杯容量 × 杯数**记录(默认 250ml × 5 杯,可改),环形进度 + 一键记一杯 / 撤销 / 自定义 ml
- 只记今天(与正在查看的历史日期无关),近 7 天柱状图

### 📊 我的

- 身高体重算 **BMI**(中国成人标准:偏瘦 <18.5 / 正常 18.5–23.9 / 超重 24–27.9 / 肥胖 ≥28),色带指针
- 体重历史;体重同时用于喝水建议

## 安卓安装包(APK)

Release 里提供 daily-fit-1.4.2.apk(约 70KB,Android 7.0+),安装后是独立 App(桌面名字是「小橘爱运动」),不用联网。

1. 下载 APK 到手机(微信/QQ 传文件可能改名,建议浏览器下载或数据线拷贝)
2. 点击安装 → 提示「未知来源应用」时允许
3. 打开「小橘爱运动」即可

> APK 就是把同一套网页资源装进 WebView 的容器:资源通过 `https://appassets.androidplatform.net/`
> 映射到 APK 内的 `assets/public/`,所以 localStorage、Canvas 都照常工作。
> 不想装 APK 也可以浏览器打开 Pages 地址后「添加到主屏幕」,功能完全一样。

安卓源码在 [android/](android/),打包脚本见 [tools/build_apk.py](tools/build_apk.py) 与 [docs/BUILD_ANDROID.md](docs/BUILD_ANDROID.md)。

## 技术说明

- **零依赖零构建**:原生 HTML/CSS/JS 单页
- 数据模型:`localStorage` 键 `fitlog_v1`
  - `profile`:{ heightCm, weightKg, cupMl, cupsGoal, weightLog[] }
  - `days['YYYY-MM-DD']`:{ type: cardio|strength|rest, items:[{name,detail,done}], cups, cupTimes[], confirmed, confirmedAt, dirty }
- PWA:`manifest.webmanifest` + `sw.js`(网络优先、断网回落缓存)
- 自测:`node tools/smoke_test.js` —— 用 `node:vm` 造假 DOM,60 项断言覆盖日历、类型、项目、
  确认流程、喝水、BMI、路由、横向溢出回归

目录结构:

    index.html            三个页面 + 底部 Tab
    css/style.css         移动端优先样式(含日历)
    js/app.js             全部逻辑(存储 / 渲染 / 事件),约 500 行
    sw.js                 Service Worker
    manifest.webmanifest  PWA 清单
    icons/                应用图标
    android/              安卓 WebView 外壳源码(Java + res)
    docs/BUILD_ANDROID.md 用 SDK 命令行打包 APK(不用 Gradle)
    tools/smoke_test.js   仿 DOM 自测(60 项)
    tools/build_apk.py    一条命令打 APK
    tools/make_icons.py   图标生成脚本(Pillow)
